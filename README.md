# InstaView — Instagram UI Clone (Project 07)

A responsive social feed interface inspired by common photo-sharing app patterns. This is an independent frontend practice project, not the official Instagram service and not affiliated with Meta.

## Features
- Desktop sidebar and mobile bottom navigation
- Horizontal stories row
- Feed posts with photos, captions, likes, saves, and comments UI
- Double-click post image for a heart animation
- Follow/unfollow demo buttons and toast notifications
- Search feed by account name or caption
- Create a caption-only post in a modal; new post appears locally in the feed
- Responsive layout for desktop, tablet, and mobile
- Sample imagery loaded from Unsplash URLs

## Run locally
1. Extract the project folder.
2. Open `index.html` in VS Code.
3. Use the Live Server extension, or open `index.html` in a browser.
4. Internet access is needed to load the remote images and Google Fonts.

## Deploy on GitHub Pages
1. Create a repository named `instagram-ui-clone`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Add the published URL to the repository description.

## AI disclosure
AI assistance was used to scaffold and refine parts of this practice project. Review and customize the code before submission. Be prepared to explain the responsive sidebar, CSS breakpoints, event listeners, and like/save state.

## Important
This is a static UI demo. It does not connect to Instagram, store accounts, upload photos, or send messages/comments to a server. The create-post feature is local to the current page and resets on refresh.
